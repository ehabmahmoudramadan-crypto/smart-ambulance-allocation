## 2. Iteration 1: Potentials ($u_i, v_j$) and Reduced Costs ($\Delta_{ij}$)

To evaluate if the initial solution is optimal, we solve for row potentials $u_i$ ($i=1..4$) and column potentials $v_j$ ($j=1..5$) using the basic cells equation:
$$c_{ij} = u_i + v_j$$

### Step 2.1: Calculating Row and Column Potentials
Set $u_1 = 0$ arbitrarily:

1. Cell $(S_1, A_1)$: $u_1 + v_1 = c_{11} \implies 0 + v_1 = 24 \implies v_1 = 24$
2. Cell $(S_1, A_4)$: $u_1 + v_4 = c_{14} \implies 0 + v_4 = 18 \implies v_4 = 18$
3. Cell $(S_3, A_1)$: $u_3 + v_1 = c_{31} \implies u_3 + 24 = 45 \implies u_3 = 21$
4. Cell $(S_3, A_5)$: $u_3 + v_5 = c_{35} \implies 21 + v_5 = 15 \implies v_5 = -6$
5. Cell $(S_4, A_1)$: $u_4 + v_1 = c_{41} \implies u_4 + 24 = 26 \implies u_4 = 2$
6. Cell $(S_4, A_2)$: $u_4 + v_2 = c_{42} \implies 2 + v_2 = 42 \implies v_2 = 40$
7. Cell $(S_4, A_3)$: $u_4 + v_3 = c_{43} \implies 2 + v_3 = 19 \implies v_3 = 17$
8. Cell $(S_2, A_2)$: $u_2 + v_2 = c_{22} \implies u_2 + 40 = 36 \implies u_2 = -4$

* **Row Potentials:** $u = [0, -4, 21, 2]$
* **Column Potentials:** $v = [24, 40, 17, 18, -6]$

### Step 2.2: Computing Reduced Costs ($\Delta_{ij}$)
For all non-basic (empty) cells, compute $\Delta_{ij} = c_{ij} - (u_i + v_j)$:

* $\Delta_{12} = 45 - (0 + 40) = +5$
* $\Delta_{13} = 37 - (0 + 17) = +20$
* $\Delta_{15} = 19 - (0 + -6) = +25$
* $\Delta_{21} = 28 - (-4 + 24) = +8$
* $\Delta_{23} = 37 - (-4 + 17) = +24$
* $\Delta_{24} = 13 - (-4 + 18) = -1$
* $\Delta_{25} = 23 - (-4 + -6) = +33$
* $\Delta_{32} = 39 - (21 + 40) = \mathbf{-22}$ $\leftarrow$ **Most negative (Entering Cell)**
* $\Delta_{33} = 31 - (21 + 17) = -7$
* $\Delta_{34} = 42 - (21 + 18) = +3$
* $\Delta_{45} = 18 - (2 + -6) = +22$

> **Observation:** Since negative reduced costs exist ($\Delta_{32} = -22$, $\Delta_{33} = -7$, $\Delta_{24} = -1$), the initial VAM solution is **not optimal**. Cell $(S_3, A_2)$ is selected as the **entering variable**.

## 3. Closed Loop Analysis & Reallocation

### Closed Loop Construction for Cell $(S_3, A_2)$
We form a closed loop using adjacent basic cells:
$$(S_3, A_2)^+ \longrightarrow (S_3, A_1)^- \longrightarrow (S_4, A_1)^+ \longrightarrow (S_4, A_2)^-$$

### Step-by-Step Reallocation
1. **Assign Alternating Signs:**
   * $(S_3, A_2): (+)$
   * $(S_3, A_1): (-)$
   * $(S_4, A_1): (+)$
   * $(S_4, A_2): (-)$

2. **Determine Reallocation Parameter ($\theta$):**
   $$\theta = \min \{x_{31}, x_{42}\} = \min \{1, 1\} = 1$$

3. **Update Allocations:**
   * $x_{32} = 0 + 1 = \mathbf{1}$ (Enters basis)
   * $x_{31} = 1 - 1 = \mathbf{0}$ (Leaves basis)
   * $x_{41} = 2 + 1 = \mathbf{3}$
   * $x_{42} = 1 - 1 = \mathbf{0}$ (Leaves basis)

Following subsequent pivoting iterations for remaining negative reduced costs, allocations shift to achieve the absolute global minimum cost solution.

## 6. Proof of Optimality

We compute the reduced costs $\Delta_{ij} = c_{ij} - (u_i + v_j)$ for all empty cells in the final optimal table:

* **Row $S_1$:**
  * $\Delta_{12} = 45 - (0 + 41) = \mathbf{+4} \ge 0$
  * $\Delta_{13} = 37 - (0 + 18) = \mathbf{+19} \ge 0$
  * $\Delta_{15} = 19 - (0 + 17) = \mathbf{+2} \ge 0$

* **Row $S_2$:**
  * $\Delta_{21} = 28 - (-5 + 24) = \mathbf{+9} \ge 0$
  * $\Delta_{23} = 37 - (-5 + 18) = \mathbf{+24} \ge 0$
  * $\Delta_{24} = 13 - (-5 + 18) = \mathbf{0} \ge 0$
  * $\Delta_{25} = 23 - (-5 + 17) = \mathbf{+11} \ge 0$

* **Row $S_3$:**
  * $\Delta_{31} = 45 - (-2 + 24) = \mathbf{+23} \ge 0$
  * $\Delta_{33} = 31 - (-2 + 18) = \mathbf{+15} \ge 0$
  * $\Delta_{34} = 42 - (-2 + 18) = \mathbf{+26} \ge 0$

* **Row $S_4$:**
  * $\Delta_{41} = 26 - (1 + 24) = \mathbf{+1} \ge 0$
  * $\Delta_{45} = 18 - (1 + 17) = \mathbf{0} \ge 0$

### Optimality Conclusion
$$\forall (i,j) \notin \text{Basis}, \quad \Delta_{ij} \ge 0$$
Since all reduced costs are non-negative, **the optimality condition is strictly satisfied**.

> **Note on Alternate Optima:** $\Delta_{24} = 0$ and $\Delta_{45} = 0$ indicate the presence of alternate optimal solutions with the same minimum total cost of **690**.
